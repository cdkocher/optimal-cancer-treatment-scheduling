Optimal Cancer Treatment Scheduling

This repository creates code to reproduce the results of the paper "Adaptive and sequential cancer therapies emerge from treatment schedule optimization" by Charles D. Kocher, Joseph O. Deasy, Damon R. Reed, Larry Norton, and Corey Weistuch. All figures from the paper can be created using the file "main.ipynb". A utility for plotting data from MSK-CHORD [Jee et al. Nature 2024] can be found in "CHORD_utils", while the optimization algorithm from our paper is contained in "schedule_utils.py".
